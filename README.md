# Java Recipe Manager (CP213 Project)

This is a Java desktop application built for a course project. It exists purely to manage recipes and demonstrate Object-Oriented Programming principles.


## Features:

Recipe Management: Add, delete, and view recipes (Title, Ingredients, Instructions, etc).

Collection Use: Uses the ArrayList class to hold all recipe data.

GUI: A graphical interface built using Java/Swing.

Input Validation: Has basic Exception Handling to prevent immediate failure when you put in garbage data.


## Setup & Running

Clone this repository.

Open the project in IntelliJ.

Compile and run.
